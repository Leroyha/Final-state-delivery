# 文档导航

[English](README.md) | [简体中文](README.zh-CN.md)

Final-State Delivery 由一份规范文件和多组说明性文档组成。

## 规范文件

- [`../AGENTS.md`](../AGENTS.md)：项目级最终状态交付规则，保持英文版本。
- [`../templates/AGENTS.zh-CN.md`](../templates/AGENTS.zh-CN.md)：可复制的中文说明模板。
- [`best-practices.zh-CN.md`](best-practices.zh-CN.md)：说明如何在规划、实现和审查阶段使用规范。

## 分析文档

- [`problem-statement.zh-CN.md`](problem-statement.zh-CN.md)：定义被否决上下文泄漏及其表现。
- [`llm-analysis.zh-CN.md`](llm-analysis.zh-CN.md)：分析可能的 LLM 和上下文机制。
- [`vibe-coding-analysis.zh-CN.md`](vibe-coding-analysis.zh-CN.md)：说明该问题与 AI 辅助开发工作流的关系。
- [`anti-patterns.zh-CN.md`](anti-patterns.zh-CN.md)：整理常见反模式。
- [`agent-adapters.zh-CN.md`](agent-adapters.zh-CN.md)：说明如何适配常见 AI 编程工具。
- [`evaluation.zh-CN.md`](evaluation.zh-CN.md)：提供评估场景和验收标准。
- [`references.zh-CN.md`](references.zh-CN.md)：列出参考资料。

## 案例

- [`examples/tomato-egg.zh-CN.md`](examples/tomato-egg.zh-CN.md)：核心案例。
- [`examples/feature-removal.zh-CN.md`](examples/feature-removal.zh-CN.md)：删除功能案例。
- [`examples/scope-boundary.zh-CN.md`](examples/scope-boundary.zh-CN.md)：作用域边界案例。

案例用于解释问题，不会自动成为规范。一个容易记住的事故不能仅凭记忆升级为项目永久约束。
