# Documentation Guide

Final-State Delivery has one normative artifact and several explanatory artifacts.

## Normative material

- [`../AGENTS.md`](../AGENTS.md) is the repository-level rule.
- [`../templates/AGENTS.md`](../templates/AGENTS.md) is the copyable minimal version.
- [`best-practices.md`](best-practices.md) explains how to apply the rule during planning, implementation, and review.

## Explanatory material

- [`problem-statement.md`](problem-statement.md) defines rejected-context leakage.
- [`llm-analysis.md`](llm-analysis.md) discusses plausible mechanisms and evidence limits.
- [`vibe-coding-analysis.md`](vibe-coding-analysis.md) places the problem in AI-assisted development.
- [`anti-patterns.md`](anti-patterns.md) catalogs common manifestations.
- [`agent-adapters.md`](agent-adapters.md) gives tool-neutral adaptation guidance.
- [`evaluation.md`](evaluation.md) gives scenarios and an acceptance rubric.
- [`references.md`](references.md) lists background research.

## Case material

The examples are deliberately separate from the normative rule. A memorable incident can explain a problem, but it should not become a permanent project constraint merely because it was memorable.
